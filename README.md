# 🚀 Minimalist Developer Portfolio

A modern, responsive, and performance-oriented developer portfolio built with **Next.js (App Router)**, **TypeScript**, and **Tailwind CSS**.

🔗 **Live Demo:** [aleor25.vercel.app/](https://aleor25.vercel.app/)

---

## ✨ Features

- **Internationalization (i18n):** Client-side localized language switcher (English / Spanish).
- **Interactive UI:** Smooth transitions, responsive carousel for project mockups, dynamic scroll detection, and clipboard helpers.
- **Optimized Assets:** High-performance images configured via `next/image` with remote patterns and high-density rendering.
- **Type-Safe Architecture:** Strict TypeScript definitions across project data, badges, and localization keys.

---

## 🛠️ Tech Stack

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Icons:** React Icons (`react-icons/si`, `react-icons/ri`, `react-icons/tb`)
- **Deployment:** Vercel

---

## 💻 Getting Started

### Prerequisites
Make sure you have Node.js (v18+) and npm installed.

### Installation

1. Clone the repository:

	```bash
	git clone [https://github.com/aleor25/portfolio.git](https://github.com/aleor25/portfolio.git)
	cd portfolio
	```

2. Install dependencies:

	```bash
	npm install
	```

3. Run the development server:

	```bash
	npm run dev
	```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.
